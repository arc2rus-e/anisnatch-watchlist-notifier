# Changelog

## v1.2.2 — 2026-11-12

- **Fix:** AniSnatch moved to **anisnatch.to**, which stopped checks working on older versions. The extension now uses the new domain. Sign in at [anisnatch.to](https://anisnatch.to) in the same Chrome, then reload the extension.
- **New:** the "Caught up" list shows the last episode you watched, and clicking it takes you back to it.
- **New setting:** *Open episode links in a new tab*. Turn it off to load an episode in the tab you're already on.
- A failed check now shows the actual reason in the popup instead of a generic message.

Earlier versions are on the [releases page](https://github.com/arc2rus-e/anisnatch-watchlist-notifier/releases).
